Одна команда

Установите движок. Выберите интерфейс.

Программа установки использует неизменяемый архив исходного кода, проверяет его хеш, собирает пакет и устанавливает команду MCP.

Linux и macOS

Требуются Node.js 24.9 или новее и Corepack.

Windows

Запускайте в PowerShell 5.1 или новее с Node.js 24.9 или новее.

Подключите OMP, DeepSeek Harness или другой клиент MCP

OMP 18.17.0

omp plugin link "$PWD" --scope project
omp plugin list --json

DeepSeek Harness 0.2.2-rc.1

dsh plugin --profile voxellume-test add ./voxellume-0.1.0.tgz \
  --ignore-scripts --config.auto-install-peers=false
dsh --profile voxellume-test --dump-config

Встроенный MCP

{
  "mcpServers": {
    "voxellume": { "command": "voxellume-mcp" }
  }
}

Текущее ограничение

Ноль поддерживаемых целей. Намеренно.

Для всех 68 ячеек определены явные результаты, но ни одна не прошла полную матрицу сборки, сервера, GameTest, готового JAR, реального клиента и визуальной проверки. Создание новых проектов будет заблокировано, пока это не изменится.
