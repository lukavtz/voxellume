01 / 05

从模组开始，而不是工具链。

用自然语言描述游戏玩法、资源、兼容性和验收标准。

输入：带版本的自然语言请求
OMP 扩展工具 DeepSeek Harness 包 基于 stdio 的原生 MCP

一条命令

安装引擎。选择你的界面。

安装程序使用不可变源代码归档，验证其哈希，构建软件包并安装 MCP 命令。

Linux 和 macOS

需要 Node.js 24.9 或更高版本以及 Corepack。

Windows

在 PowerShell 5.1 或更高版本中使用 Node.js 24.9 或更高版本运行。

连接 OMP、DeepSeek Harness 或其他 MCP 客户端

OMP 18.17.0

omp plugin link "$PWD" --scope project
omp plugin list --json

DeepSeek Harness 0.2.2-rc.1

dsh plugin --profile voxellume-test add ./voxellume-0.1.0.tgz \
  --ignore-scripts --config.auto-install-peers=false
dsh --profile voxellume-test --dump-config

原生 MCP

{
  "mcpServers": {
    "voxellume": { "command": "voxellume-mcp" }
  }
}
